# adibamba.github.io

Personal portfolio for Abdoulie A. Jallow. Plain HTML, CSS and a small JS file, no build step.

Live at https://cloudfix.tech (custom domain set by the CNAME file).

## Files
- `index.html` page content
- `assets/styles.css` styles (light and dark mode follow the visitor's system setting)
- `assets/main.js` mobile menu and footer year
- `assets/Abdoulie_Jallow_CV.pdf` CV linked from the Download CV buttons
- `assets/profile.jpg` portrait (replace this file to change the photo)

## Edit locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.
